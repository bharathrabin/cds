# CDS

cds is a collection of data structures implemented in c. 

## Why does cds exist? 
Educational curiosity mostly. I learned how to code using the C programming language. This was back between the years 2007 - 2012. 
We were using C99. Fast-forward to 2026, we now have a really solid improvement on that with C11. So I will be using that as a 
standard to implement some data structures. Kicking it off with really simple ones and increasingly will bump up the difficulty. 

## Currently implemented

| Data Structure | Status | Notes on testing | Notes on implementation |
|---|---|---|---|
| Dynamic Array | Implemented | Tested relatively well | Standard dynamic array with a len and a cap. Simplest possible implementation |
| Singly Linked List | In-Progress | Testing in progress |Accepts void* payload, has a means to configure payload memory management |
